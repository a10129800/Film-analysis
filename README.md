Windows 版拉片工具。

## 功能

- 🎬 影片播放
- ✂️ SHOT 標記
- 🖼️ 自動產生影片縮圖
- 🎞️ 景別標記
- 📝 SHOT 筆記
- 💾 專案儲存／載入
- 📤 匯出 Obsidian Markdown
- ⚙️ FFmpeg 縮圖處理

## 使用方式

下載下方的 `ShotBreakdownAssistant_v1.2.zip`，
解壓縮後直接執行：

`ShotBreakdownAssistant_v1.2.exe`

不需要另外安裝 Python。
